# s52-t16 — how the app makes a course's GUID (#6), from the corpus

**Status:** DONE

**In one paragraph:** The GUID is a random version-4 UUID in .NET's `System.Guid` byte order, minted when a course is created and kept through edits and re-shares; the share code, not the GUID, is per upload. All 639 non-zero GUIDs in 640 courses parse as RFC 4122 version 4 read as `bytes_le` (in big-endian order the version nibble is anything). 14 GUID values recur across 2 to 9 share codes, and each group is visibly one course at different stages (rail and cell counts close but not equal). The one zero GUID is traxgen's own `FLW4TMLP5V`, which the app accepted and certified -- so the app does not require a v4 GUID to load a course. Whether it uses the GUID for anything (dedup, "same course" detection) is unknown.
