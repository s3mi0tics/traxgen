# traxgen — Documents

Local copies of reference material for this project — vendored docs, PDFs, saved pages: anything Claude should read from disk rather than fetch. Keep something here when you want it local (offline access, or pinning a version against drift); to just point at an external doc, repo, or site, add it to `../resources.md` instead.

Entries use the same shape as `resources.md` and skills — `name`, a `description` (when to reach for it), and a `location` (here, the filename in this folder).
