# Decisions and observations — index of every entry this project holds

**This is an index, not the record.** Each line is that entry's own first
sentence, verbatim — never a summary, never rewritten. The reasoning, evidence,
scope and exceptions are NOT here; they are in `decisions.md` and
`observations.md`, which are complete, unmodified and still in force. Nothing
has been retired, moved or demoted.

`body NNNw` is the length of what this line is not showing. A **[AMENDED]** or
**[SUPERSEDED]** flag means the body changes or reverses what the title says —
**those are never safe to act on from this file.** 8 of these decision titles carry one.

Look one up by the line address on its own line — exact, and unaffected by any
punctuation in a title that a literal `grep` would trip over:

    sed -n '127p' allostatik/decisions.md
    sed -n '412p' allostatik/observations.md

Line addresses are regenerated with this file, so they are current whenever the
open's verify passes. `D` numbers are positional in file order; both files are
append-only, so they are stable in practice, but an insert would renumber below it.

Generated by `uv run python -m scripts.make_record_index`; regenerated at close
and checked at the open (`--verify`). Do not hand-edit — edits belong in the two
files above.
